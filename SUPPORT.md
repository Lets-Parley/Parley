# Support

Parley is maintained by a small community without a paid support team or
on-call rotation.

## Questions and help

Use [GitHub Discussions](https://github.com/lets-parley/parley/discussions) for
setup questions, troubleshooting, deployment advice, and ideas that still need
design work. Search existing discussions and the
[documentation](https://www.letsparley.io) first; include the Parley version,
deployment method, relevant configuration with secrets removed, and the exact
error or log message.

## Actionable defects and accepted work

Use an [issue](https://github.com/lets-parley/parley/issues/new/choose) for a
reproducible bug or an actionable feature that is ready for project tracking.
The issue forms explain what information is useful. Maintainers may move an
open-ended support or design request to Discussions.

## Security and conduct

Do not disclose a suspected vulnerability in Discussions or Issues. Follow
[SECURITY.md](SECURITY.md) to report it privately. Report harassment or other
Code of Conduct concerns confidentially to
[conduct@letsparley.io](mailto:conduct@letsparley.io).
