Parley is a self-hosted tool that a team joins by following a link. That shapes
everything below: the interesting questions are what a room code actually
protects, what an operator is trusted to configure correctly, and what a database
dump would disclose.

These pages state what is enforced, what is deliberately not, and what is simply
absent. Where something is absent there is a mitigation next to it — a gap with
an answer is a decision, a gap without one is a hole.

:::note[Reviewing Parley for your organisation?]
The [Security review pack](/security/review-pack/) is a single page that collects
the threat model, the data inventory, the supply-chain position and every known
limitation, so you can read or print one document instead of eight.
:::
