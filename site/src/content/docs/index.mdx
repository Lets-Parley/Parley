## Most tools want an account. Parley wants a link.

No seat count, no workspace, no credit card before anyone can vote on a story.
Name a space, share the link, and the people who open it are at the table.

The frontend is compiled into the binary, so there is no second service, no Node
runtime in production, and nothing to keep in sync. Point a container at a
database and you have somewhere for your team to sit.

```sh
git clone https://github.com/jacorbello/parley && cd parley
cp .env.example .env        # set POSTGRES_PASSWORD to anything
docker compose up -d
```

## It behaves itself in production

`/healthz` never touches the database, so a blip can't restart the pod and drop
every WebSocket. `/readyz` does. Migrations apply at boot, and a binary older
than its database refuses to start rather than corrupt it. Logs are structured
JSON. Exports escape spreadsheet formulas.
