## Scale and availability

<Capability rows={[
  { name: "Multiple replicas", status: "built", detail: "Fanout runs over Postgres <code>LISTEN</code>/<code>NOTIFY</code>, presence and the room-code throttle are rows in Postgres, and simultaneous boots serialize their migrations behind an advisory lock. The socket hub is still per pod, but nothing depends on one pod seeing every socket. Not yet exercised on a real multi-node cluster." },
  { name: "Zero-downtime deploys", status: "built", detail: "The chart rolls with <code>maxSurge: 1</code> / <code>maxUnavailable: 0</code> above one replica. During the rollout old pods serve against the newer schema the new pod migrated to; migrations are additive, so that is fine, and it resolves as the rollout replaces them. At <code>replicaCount: 1</code> there is still a reconnect." },
  { name: "Connection migration during deploy", status: "not-built", detail: "Shutdown closes a pod's WebSockets rather than handing them over; clients reconnect and land on a surviving replica. The reconnect is visible, the state is not lost." },
  { name: "Published performance numbers", status: "not-built", detail: "There is no benchmark, and inventing one would be dishonest. Watch Postgres first — that is where the pressure lands." },
]} />

## Operations

<Capability rows={[
  { name: "Metrics, tracing, request IDs, access log", status: "not-built", detail: "JSON logs to stdout are all Parley emits. Blackbox-probe <code>/readyz</code>, and take request metrics and access logs from your reverse proxy. See <a href='/operations/observability/'>Observability</a>." },
  { name: "Backups", status: "not-built", detail: "Nothing backs itself up. Schedule <code>pg_dump</code>." },
  { name: "Data retention or cleanup", status: "not-built", detail: "Application records are never deleted automatically. Session authorization expires, but <code>session_tokens</code> rows are not swept; prune them yourself if the instance runs for years." },
  { name: "Down-migrations or rollback", status: "not-built", detail: "Migrations are forward-only and the binary refuses to start against a newer schema. Roll back by restoring a backup taken before the upgrade." },
  { name: "A bind-address setting", status: "not-built", detail: "The process listens on all interfaces; only <code>PORT</code> is configurable. Use a container port binding, a firewall, or a proxy." },
  { name: "Configuration reload", status: "not-built", detail: "Everything is read once at boot. Restart to change anything." },
]} />

## Access and identity

<Capability rows={[
  { name: "Space roles — owner, admin, read-only", status: "not-built", detail: "Any member can rotate the room code or open the space. Story mutations and session controls are facilitator-only; ordinary members retain voting and their own standup entries." },
  { name: "Per-user or per-team space access", status: "not-built", detail: "A room code gates a space; identity does not. Gate the whole instance with an SSO proxy if you need this today." },
  { name: "Removing a member", status: "not-built", detail: "Rotate the code — that retires the old one immediately. Existing members remain members." },
  { name: "Account linking when switching to OIDC", status: "not-built", detail: "Anonymous and federated identities are distinct. Existing history remains under the old display records; federated users rejoin spaces with their room codes." },
  { name: "Sign out everywhere or admin revocation UI", status: "not-built", detail: "Delete rows from <code>session_tokens</code> in SQL. HTTP rejects them immediately; WebSockets start a check every 30 seconds, allow a 30-second timeout, and close with code 1008 on failure. There is no admin surface." },
  { name: "Account deletion or data-subject tooling", status: "not-built", detail: "SQL against the documented schema; note that deleting a user who facilitated a session is blocked by a foreign key." },
  { name: "Audit log", status: "not-built", detail: "Rows carry <code>user_id</code> and timestamps. Reconstruct from Postgres." },
]} />

## Security posture

<Capability rows={[
  { name: "SBOM and provenance", status: "built", detail: "Releases produced by the hardened workflow include an SPDX SBOM, digest-qualified deployment manifests, maximum build provenance, and a GitHub attestation for the final GHCR digest. Releases v0.1.0 through v0.2.1 were not backfilled. See <a href='/security/supply-chain/'>Supply chain</a>." },
  { name: "Vulnerability scanning in CI", status: "built", detail: "govulncheck, CodeQL, dependency review, npm audit, and container scanning gate changes." },
  { name: "Automated dependency updates", status: "built", detail: "Dependabot checks Go, web, site, Actions, and Docker dependencies weekly." },
  { name: "HSTS and several modern headers", status: "not-built", detail: "Parley sets CSP, nosniff, X-Frame-Options and Referrer-Policy. Add HSTS, Permissions-Policy and the COOP/COEP/CORP family at your proxy." },
  { name: "General ingress rate limiting", status: "not-built", detail: "Room-code guesses and open identity creation are throttled; spaces, sessions, and stories have configurable caps. General API calls and WebSocket connections still need ingress controls." },
  { name: "Encryption at rest", status: "not-built", detail: "Use an encrypted volume or your provider's encryption." },
  { name: "Room codes hashed at rest", status: "out-of-scope", detail: "Deliberate: a code is meant to be readable by members and passed on. A database dump therefore discloses every code. See the <a href='/security/threat-model/'>threat model</a>." },
]} />
