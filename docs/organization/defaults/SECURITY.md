# Security

Do not open a public Issue or Discussion for a suspected vulnerability. Use the
affected repository's private vulnerability-reporting page. If that is
unavailable, email
[security@letsparley.io](mailto:security@letsparley.io).

The project aims to acknowledge a report within five business days, complete
initial triage within ten business days, and coordinate disclosure within 90
calendar days. Repository-specific supported-version and security-model details
take precedence over this default.
