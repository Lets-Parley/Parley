# Support

Use the repository's GitHub Discussions for questions, troubleshooting, and
ideas that still need design. Use Issues only for reproducible defects and
accepted, actionable work.

Maintainers are volunteers and do not provide an on-call or guaranteed support
service. Remove credentials, tokens, room codes, and personal information before
sharing logs. Report suspected vulnerabilities through the repository's private
vulnerability-reporting page or to
[security@letsparley.io](mailto:security@letsparley.io).
