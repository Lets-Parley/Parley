# Default community health files

These are source files for the future public `Lets-Parley/.github` repository.
They are intentionally outside this repository's active `.github` community
paths. Copy them to the root of the organization community repository only
after reviewing them against the repository-specific policies.

The defaults route contributors to each repository's own files when present and
otherwise establish Discussions for support/design, Issues for accepted
actionable work, private vulnerability reporting, Contributor Covenant 2.1, and
DCO sign-off.
