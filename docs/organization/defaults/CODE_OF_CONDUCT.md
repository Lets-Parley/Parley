# Code of Conduct

Lets Parley repositories use the [Contributor Covenant Code of Conduct, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
Repository-specific copies name the enforcement contact. Confidential reports
may be sent to [conduct@letsparley.io](mailto:conduct@letsparley.io).

The Contributor Covenant is available from its authors under its stated terms;
preserve the full text, attribution, and links when adding it to a repository.
