# Lets Parley

Lets Parley builds small, self-hosted tools that help teams run useful meetings
without handing their work to a hosted service.

Our first project is [Parley](https://github.com/lets-parley/parley): planning
poker and daily standups in one Go binary plus Postgres.

- [Documentation](https://www.letsparley.io)
- [Project discussions](https://github.com/lets-parley/parley/discussions)
- [Security reporting](https://github.com/lets-parley/parley/security/advisories/new)

Contributions are welcome. Read each repository's contributing, support,
security, governance, and conduct policies before opening work.
