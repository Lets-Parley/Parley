# Future organization community repository sources

This directory is a source set for a future public `Lets-Parley/.github`
repository. GitHub does **not** treat anything here as an active organization
profile or default community-health file in this repository.

- `profile/README.md` is the copy-ready organization profile.
- `defaults/` contains reusable community-health defaults for repositories that
  do not provide their own policy.

Repository-specific files always take precedence. Before publishing this source
set, review every link and contact address, create the public `.github`
repository, and copy `profile/` and the contents of `defaults/` to their special
GitHub locations. Publishing and verifying those external settings is separate
work.
